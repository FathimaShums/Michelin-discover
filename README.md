# Michelin Discover 🍽️✨

Full-stack restaurant explorer application leveraging the Michelin Guide 2021 dataset. Built with React, Express, MongoDB, and Leaflet.

## Project Structure
- `backend/`: Express + Mongoose API server.
- `frontend/`: Vite + React + Tailwind CSS client.
- `scripts/`: Data cleaning and dataset transformation utilities.
